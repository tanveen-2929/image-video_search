# 🔍 Image & Video Search

A simple web-based project that allows users to search and view images and videos from a dataset using keywords or predefined categories.

---

## ✨ Features

- 🔎 Search images and videos by keywords  
- 🖼️ Display image results  
- 🎥 Display video results  
- ⚡ Simple and fast UI  
- 📱 Responsive design  

---

## 🧠 How It Works

1. User enters a search keyword  
2. The system filters matching images/videos  
3. Results are displayed instantly on the page  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript
